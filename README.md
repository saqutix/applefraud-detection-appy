# 🍎 AppleFraud Detection

**AI-powered credit card fraud detection with 99.96% accuracy**

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_App-success?style=for-the-badge&logo=render)](https://applefraud-detection-appy.onrender.com)

##  Performance

| Metric | Score |
|--------|-------|
| **Accuracy** | 99.96% |
| **Precision** | 92.94% |
| **Recall** | 85.71% |
| **F1 Score** | 87.05% |
| **ROC-AUC** | 97.87% |

## Features

-  Upload CSV transactions
-  AI fraud detection (XGBoost)
-  Probability & risk levels
-  Download results CSV
-  Feature importance

##  Tech

- Python 3.12 · Flask · XGBoost
- Scikit-learn · Pandas · NumPy
- Deployed on Render

##  Quick Start

```bash
git clone https://github.com/saqutix/applefraud-detection-appy.git
```
